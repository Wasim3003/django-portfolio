Lab notes

Short write-ups of what I learned while building.

Note 01: Why Redis sits in front of the GitHub API

GitHub Searcher called the GitHub API for every search, so repeat searches wasted time. I added Redis with a 2-hour TTL so repeat searches skip the network. Pick a cache lifetime from how often the data really changes.

Note 02: A chatbot on Groq’s free tier

My chatbot uses a Django REST backend that calls LLaMA3-70B on Groq. Keeping the API key on the server and validating input in the view kept the setup simple and safe.

Note 03: Building this portfolio

A Three.js arc reactor, a Django view that emails contact messages, a small game and an assistant that answers from my resume. Each piece was a chance to practise something new.
